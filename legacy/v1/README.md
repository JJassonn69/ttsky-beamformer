# Legacy two-channel prototype

This directory preserves evidence and helper code from the original
two-channel prototype. It is historical provenance only. The active
four-channel submission is defined by root `info.yaml`, `gds/`, `lef/`,
`src/project.v`, `submission/template.lock`, and the `v2/` implementation.

`images/` contains the former root datasheet renderings, and `submission/`
contains the former root evidence records. They remain grouped with the
revision they actually describe.

No active Make or GitHub workflow target reads this legacy directory.
