# Archived two-channel submission evidence

These are the JSON, text, and extracted-SPICE evidence records from the
original two-channel prototype. Their hashes, simulations, 1x2 boundary, and
official action run do not apply to the active four-channel V2 candidate.

The complete historical tree, including its matching GDS, LEF, lock file, and
runnable helper paths, is preserved at release commit
`91749fe4298b00708b150c9e0df9752d59cc74fe`. The relocated helper copies in
`legacy/v1/tools/` are for source inspection; use that commit to reproduce the
old release without mixing old evidence with current artifacts.
